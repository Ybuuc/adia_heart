# Сердце для Адии ♡

Готовый адаптивный сайт для GitHub Pages. Сердце из слов автоматически собирается при открытии страницы, затем мягко пульсирует. Кнопки показывают новые комплименты и повторяют анимацию. Нет внешних библиотек, запросов, отслеживания и установки зависимостей.

## Как опубликовать

1. Распакуйте архив.
2. Создайте на GitHub новый публичный репозиторий, например `adiya-heart`.
3. Через Add file → Upload files загрузите **содержимое** папки в корень репозитория. `index.html` должен находиться сразу в корне, а не во вложенной папке. Сохраните загрузку кнопкой Commit changes. Архив ZIP загружать вместо файлов не нужно.
4. Откройте Settings → Pages.
5. В разделе Build and deployment выберите Source → Deploy from a branch.
6. Выберите ветку main и папку /(root), затем Save.
7. Дождитесь успешной публикации. Ссылка появится в Settings → Pages. Обычно адрес имеет вид https://ВАШ_ЛОГИН.github.io/adiya-heart/ .
8. Отправьте Адии эту ссылку: она откроется и на телефоне, и на компьютере.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Проверка и изменение

На компьютере можно просто открыть index.html двойным щелчком. На телефоне удобнее открывать опубликованную ссылку.
Все стили, слова и код находятся в index.html. Дополнительные комплименты редактируются в массиве compliments. Слова сердца находятся внутри SVG в элементах text.
При включённом системном уменьшении движения анимация отключается, сердце остаётся видимым.
После изменения файла на GitHub дождитесь окончания публикации. Если видна старая версия, обновите страницу или откройте ссылку в приватной вкладке.

Сайт подготовлен для публикации; этот архив сам по себе не создаёт репозиторий и не публикует страницу.
